OPTIONAL GOOGLE CONNECTION

Connect your calendar

To connect, Google needs an OAuth web-client ID for this website:

  1. Open Google Cloud, choose or create a project, and enable the Google Calendar API.
  2. Set up the OAuth consent screen and add the Google account you’ll connect as a test user if Google asks.
  3. Create an OAuth client ID → Web application. Add this exact origin under Authorized JavaScript origins: https://brightwebs.github.io. For local testing, also use http://localhost:5173.
  4. Paste the client ID below, save, then choose Connect and approve Google’s access request.

Only the public client ID belongs here—never paste a client secret. Google requires the authorized origin to match exactly.

When you connect, Google will ask permission to read, add, edit, and delete calendar events. Brixie keeps the temporary sign-in token in memory, not in saved browser storage. Disconnect or remove Brixie’s access from your Google Account at any time. Google may show an unverified-app warning while your OAuth project is in testing.
